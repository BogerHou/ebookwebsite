# Vercel 额度与成本验收

本站的实现、资源调用改动和每次上线，均须遵守 `AGENTS.md` 的成本要求。通用审查方法由本机的 `vercel-cost-guard` skill 提供；本文件和回归脚本保留项目具体约束，其他贡献者无需安装该 skill 也能执行。

## 必须保持的行为

- 默认首页、12个分类详情、3个目录分页、联系页，以及全部书籍、指南、帮助等公开规范页面，在构建时输出完整HTML。生产构建的 `prerender-manifest.json` 必须覆盖所有108个规范页面。不能因在Page或metadata中读取请求参数而让这些默认页面恢复逐请求执行。
- 搜索、排序、分类分页和带书籍上下文的反馈链接仍保留原URL和服务端初始内容；请求参数通过静态路由规则送往独立动态查询渲染。查询页面不加入sitemap，canonical和noindex沿用原有逻辑。不能用纯客户端空壳、强制静态吞掉查询，或公共缓存所有查询响应代替这一设计。
- 查询分页与反馈使用原生链接发起文档导航；Next客户端对同路径静态内容的乐观缓存假定重写不依赖查询参数，与本站的查询路由不兼容。浏览器验收先访问默认路径，再导航到该路径的查询版本，检查列表、反馈书名及元数据；只检查直接HTTP请求会漏掉此问题。
- 分类和分页的未知地址返回真实HTTP404。纯路径校验不再需要Node Proxy；未来需要认证或其他必要中间件时，先明确匹配范围、业务理由和计费影响，再更新回归约束。
- 密集书目、专题卡片、分类列表、封面架和分页链接只在点击后请求目标页面；主导航可保留有价值的预取。所有链接保留可抓取href和正常导航。
- 书籍图片直接使用构建生成的响应式WebP；版本化衍生文件缓存一年。维护全局unoptimized和Vercel项目精确路径Deny。原图地址没有内容版本，不能直接设置一年immutable。
- 完整PDF仍在百度网盘，不进入公开部署。领取接口只由用户操作触发，并保持私有no-store和服务端访问控制；此处必要的函数调用不能通过公开分享映射省掉。GA4只在正式站点初始化一次，Cloudflare统计网关不应退回Vercel代理。
- 当前没有数据库、Blob、KV、AI调用、后台轮询、定时任务、ISR周期更新或Vercel Analytics/Speed Insights代码。引入这些服务时，必须重新检查其触发次数、缓存、边界和实际套餐额度。

## 可执行验证

`npm run check`包含源代码成本回归，`npm run build`在构建完成后检查实际产物；失败会使命令非零退出。新增书目和分类时，脚本按目录数据计算规范路径，避免只检查固定样例。

```bash
node scripts/validate-vercel-cost.mjs --source-only
node scripts/validate-vercel-cost.mjs
node scripts/validate-vercel-cost.mjs --base https://ebooknest.store --output .tooling/qa/vercel-cost-live.json
```

本地使用生产构建核对完整SEO、查询结果、分页ItemList、联系上下文、未知路径404和真实浏览器交互；上线只做少量代表页面及必要领取的确认，避免重复全站下载。图片转换探测使用不可能生成真实转换的无效参数；400仅表示参数拒绝，不能判定关闭。

## 实际用量与记录

从已授权的Vercel Usage读取套餐、时间窗口和项目/账户维度，检查函数调用/CPU/内存、CDN请求、传输、图片转换/缓存、构建及已启用集成。套餐额度由多个项目共享，不把账户总量全部归因于本站；文档中的免费额度数值不能代替实际账户和当前官方计费规则。

将修改前后构建/HTTP行为、真实用量基线、验证时间、部署链接、保留的动态调用及理由记录在内部审查产物中。账单汇总可能延迟，未更新时注明后续比较尚未验证，不不断刷新控制台，不自动安排监控任务。没有账户权限时明确缺口，继续完成可验证的项目修复；不能声称已完成全面账户额度审计。

静态/CDN请求仍消耗托管额度。此流程降低可避免的计算和传输，不承诺无限流量或整体零成本，不自动授权升级、开通付费服务或更改用户网络设置。
