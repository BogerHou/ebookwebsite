# EbookNest · 书径

[访问书径网站](https://ebooknest.store/)

书径是面向中文读者的外文原版书目录与选书指南。通过中文介绍、原书页面预览和主题导读，帮助读者了解一本书的内容、适合人群和阅读方向。

目前收录 80 本书，覆盖 12 个主题分类，提供 6 篇专题选书指南和 79 项可领取资源。

- **了解一本书**：查看书籍介绍、作者资料、目录选读、适合读者与相关书目。
- **预览原书**：浏览真实书页，了解版式、插图和内容呈现。
- **按主题选书**：通过分类目录、搜索和专题指南寻找感兴趣的书籍。
- **领取阅读资源**：在书籍详情页查看资源状态并领取可用资源。

网站源码位于 [`web/`](web/)，基于 Next.js，部署在 Vercel。运行与部署说明见 [`web/README.md`](web/README.md)。
